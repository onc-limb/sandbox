# sandbox

技術検証・技術的なお試しのためのリポジトリ。

興味を持った技術（フレームワーク・ライブラリ・ツールなど）を実際に触ってみるための**遊び場**であり、
ここにあるアプリケーションはリリース・公開・運用を目的としていない。
プロダクトとしての完成度は求めず、「その技術の強み・弱み・設計思想に触れること」を目的とする。

## ディレクトリ構成

- `next-app/` — Next.js の試用
- `on-react/` — React の試用
- `rag/` — RAG（LlamaIndex 等）の試用
- `specs/` — 試用時に使い回す共通仕様の置き場

## 共通仕様

新しい技術を評価するときに毎回使い回す固定題材の仕様を `specs/` に置いている。
